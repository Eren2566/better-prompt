Better Prompt 图标生成器

这个工具可以帮助您生成Chrome扩展所需的不同尺寸PNG图标。

📋 使用步骤：

  1. 点击下方按钮下载对应尺寸的PNG图标
  2. 将下载的图标重命名为: icon-16.png, icon-32.png, icon-48.png, icon-128.png
  3. 将这些文件放入 assets/icons/ 目录
  4. 取消注释 manifest.json 中的图标配置

32x32

🔧 手动更新 manifest.json：

图标文件准备好后，在 manifest.json 中取消注释以下配置：

"icons": {
  "16": "assets/icons/icon-16.png",
  "32": "assets/icons/icon-32.png", 
  "48": "assets/icons/icon-48.png",
  "128": "assets/icons/icon-128.png"
}
