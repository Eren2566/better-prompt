🧪 Better Prompt 插件测试页面

测试准备

测试前准备：
1. 确保已在 Chrome 中加载 Better Prompt 插件
2. 确保插件已启用并显示在工具栏
3. 点击插件图标，配置 API Key 和触发方式

支持的快捷键

📝 可用的触发方式：

三击空格： 快速连续按三下空格键
三击回车： 快速连续按三下回车键
三击 Tab： 快速连续按三下 Tab 键
三击分号： 快速连续按三下分号 (;)
Ctrl + 空格： 按住 Ctrl 键，然后按空格
Alt + 空格： 按住 Alt 键，然后按空格
Ctrl + 回车： 按住 Ctrl 键，然后按回车
